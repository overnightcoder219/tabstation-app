# TabStation

Turns an Android tablet into a desktop: a macOS-style Dock, menu bar, Launchpad and Control Center, or a Windows-style taskbar and Start. App windows get close, minimize and maximize buttons, split screen is easy to leave, and switching TabStation off brings the tablet's own launcher and gestures back. Bahasa Indonesia and English. No root (uses Shizuku), internet is only used by the optional Weather and Stocks desktop widgets.

- Website and setup guide: https://overnightcoder219.github.io/tabstation-app/
- Download: [Releases](../../releases/latest). Each release has the APK and its SHA-256.
